# so_long

A small 2D game built with MiniLibX library: collect all items and reach the exit.

## Usage

```sh
make
./so_long maps/map.ber
```

## Map format

`1` wall, `0` floor, `C` collectible, `E` exit, `P` player start. Maps must be rectangular, enclosed by walls, and solvable.

## Controls

`W` `A` `S` `D` / arrow keys to move, `ESC` to quit.
